## 第一步：判类型 + 抓主体去噪

先判这是哪类图，再决定用哪个范例/原语：

| 看到什么 | 类型 | 起步 |
|---|---|---|
| 筒体+两端封头+接管/人孔 | 压力容器示意图 | `gen_container.py` |
| 管线沿斜向走+焊口W/J+阀门+放空点+指北针+表头 | 压力管道单线图（轴测） | `gen_isometric.py` |
| 单个弯头/三通/大小头/法兰/短管 | 管件/接管 | `cadkit.py` 原语拼 |

**抓主体、去噪**（所有类型通用）：

- 忽略背景网格/坐标纸格子、图幅分区字母（D/E/F/2F 之类）、杂色笔误、涂改疙瘩、纸边阴影、手指、无关散点。
- 只保留设备/管线轮廓、接管、符号、内部结构、中心线及其连接关系。
- 网格纸手绘**靠视觉判读**，不要跑探针/连通域去"找母线"——格子线会占满图，量测必失真。

## 文字取舍规则

- **能识别的逐字保留**：中文标签（人孔/下降管/放空点/铭牌/管板）、编号（W1/J2/H1/B2/A1）、规格（D168×5.5）、表头表尾信息。编号落在它原本依附的线上，方位对应。
- **识别不了的直接忽略**：不臆造、不追问、不留占位符。潦草到认不出的字（如容器内腔的涂写、封头里的乱码）一律不画。
- 一个不多一个不少：可识别标注齐全，不可识别的不出现。

## 判读问句（逐条回答，别跳）

**容器类：**
1. 卧式/立式？视角（全剖侧视/俯视）？筒体长径比大概多少（手比刻度，判到 0.1 够用）？
2. 端部封头形式：标准椭圆(2:1,深=D/4)/碟形/半球(深=D/2)/平封头/圆锥？判成哪种就按标准几何画。
3. 每根接管：位置（顶/底/左/右封头/筒壁）、方向（垂直主体、是否过轴线或封头尖点）、有无法兰、朝外伸还是被手绘压在轮廓里。
4. 符号：对顶三角+阀杆+手轮=阀门；再带斜线=安全阀。原图两种形态不同就别统一。
5. 短管末端小波浪=折断线（管线出图，画一段就停）还是底面法兰？判错会臆造法兰盘/支座。
6. 内部：隔板占直段长百分比、分界/液位线在中心线上方还是下方、起止接到哪。有没有偏心锥段、管板、内部管束（虚线+端点圆）、铭牌框。
7. 线型：分界线原图是实线还是点划线？照原图。
8. 有没有引出线/中心线？原图没有就别加。

**单线图类：**
1. 管线走向：竖管保持竖直，水平管段画成 ±30° 斜线（轴测习惯）。逐段记节点坐标。**转弯处把两根直线延长到交点成尖角**（轴测直角拐弯），原图断开留缝也补到相交；焊口点只是管段上的标记，**不在两点间另拉连接线**。整条管线画成连续折线，拐点是相邻两段公共端点。
2. 焊口：实心点=W 焊缝，成对点套圆圈=一个口；J=口编号。记全 W/J 编号与位置。
3. 阀门/放空点：对顶三角+双短划法兰标记；放空点是短管+阀门+“放空点”标签。
4. 大小头：管线上开口梯形/菱形（异径管）。流向：实心箭头。折断线：管线出图端。
5. 规格标注沿管线方向旋转（D168×5.5 等）；表头（台账序号/管道编号/规格）、表尾（所属区域/装置）、指北针（上/北/东/西/南）照抄。

## 三类图语义对照表

**容器：**

| 手绘样子 | 判读成 | CAD 画法 |
|---|---|---|
| 上下长横带+两端圆弧 | 卧式筒体+封头 | 母线直线；封头 `arc`（标准椭圆 rx=D/4,ry=D/2） |
| 圆弧尖外小矩形+两短线 | 封头人孔（过尖点朝外，末端法兰） | `nozzle`+`flange_face`/矩形法兰 |
| 顶部两竖短线+叉/带轮横线 | 接管+阀门 | `nozzle`→`valve` |
| 上式再带斜线 | 安全阀 | `valve`+斜线 |
| 底部两竖短带末端小波浪 | 下降管/出口（非支座） | 两竖线+`breakline`，无法兰盘 |
| 舱内水平线+字母 | 分界/液位线+编号 | 细实线（按原图线型） |
| 贯通竖线+B1/B3 | 封头-筒体环焊缝+编号 | 竖线+编号落线端 |
| 中央贯通双线+B2 | 隔板 | 双竖线 |
| 偏心锥段（底平齐，顶斜升） | 异径锥段 | 顶母线斜线，底母线贯通 |
| 竖直双线/波浪线 | 管板 | 双竖线（规整化，不描波浪） |
| 虚线+两端小圆 | 内部管束/隐藏管 | `hidden`+`circle` |
| 方框+“铭牌” | 铭牌位置 | `rect`+text |

**单线图：**

| 手绘样子 | 判读成 | CAD 画法 |
|---|---|---|
| 斜向/竖向折线 | 轴测管线 | `line` 逐段，水平段 ±30° |
| 实心点（套圈成对） | 焊口 W（J 口编号） | `dot`+`circle`+W/J 标签 |
| 对顶三角+双短划 | 法兰阀门 | `valve(flanged=True)` |
| 短管+阀+“放空点” | 放空点 | `line`+`valve`+text |
| 开口梯形/菱形 | 大小头 | `reducer` |
| 实心三角箭头 | 流向 | `arrow` |
| 端部双短划/波浪 | 折断线（出图） | `breakline`/`flange_marks` |
| 斜置规格字 | 规格标注 | `text(rot=管线角)` |
| 五向箭头+上北东西南 | 指北针 | `line`+`arrow`+text |

## 归一化参数怎么取

两套无量纲量，避免像素级描线：

- 横向 `at=(x_对象-x_左交界)/(x_右交界-x_左交界)`，左交界=0、右交界=1。
- 竖向 `ratio=Δy/D`（中心线上方为正），接管尺寸类 `Δx/D`。

取值顺序：母线 y→得 D 与 cy；交界竖线 x→得直段长 L；隔板/接管/分界线位置；归一化后**取整数比**（0.491→0.49，1.98→2.0）。手绘照片有 ±20px 噪声与透视倾斜，别把噪声写进参数。单线图可直接按画布像素记节点（轴测图比例由节点坐标决定）。

## 判读结论要写进回复

交付时说明：保留了什么结构与标注；**忽略了哪些不可识别文字与背景**；做了哪些归位修正（封头按标准椭圆 D/4、接管过尖点朝外、波浪判为折断线不加法兰、管板波浪规整为双线）；比例与封头由哪个参数控制。让用户能一句话纠正判读，而不是重画。
