## 逐项质检清单

全部通过才交付。

- **主体完整、去噪到位**：设备/管线轮廓、全部接管/附件、内部结构都在；背景网格、图幅字母、涂改、杂色笔误**一律不出现**；无多余构件（多余法兰盘/支座/竖直中心线算不合格）。
- **文字取舍正确**：可识别标注逐字齐全、方位对应、编号落在依附线上；不可识别文字**不出现**（无臆造、无占位）。
- **接管方向**（容器）：每根接管垂直主体；封头接管过尖点朝外，法兰在末端（拿不准时用行探针，别只靠肉眼）。
- **符号正确**：阀门/安全阀/放空点/大小头形态与原图一致，未统一化。
- **比例合理**：长径比、封头深度、接管间距、轴测节点与判读一致；无拉伸变形。
- **规整化到位**：母线/接管/管线笔直，封头弧光滑，无手绘抖动/墨团/波浪残留（管板波浪已规整为双线）。
- **线型分层**：白底黑线；轮廓粗/结构细/中心线点划线/隐藏虚线清楚（DXF 落对应层）。
- **DXF 可用**：`dxf_check.py` 显示 `$TEXTSTYLE=CADHZ`、字体 `simhei.ttf`、全部 TEXT 引用该样式、"字体可用性: OK"。
- **同源一致**：PNG/DXF 出自同一份 SVG/参数。

## 探针复核配方（按需，非必经）

干净图或比例一眼可判时**跳过量测**。只在拿不准时用：

```powershell
# 容器接管内外侧：取中心线上下各 20~40px 的行
python <skill>\scripts\probe.py <out>.png --thr 170 rows <cy-20>,<cy+20>
# 母线 x 起止 / 交界竖线 / 隔板
python <skill>\scripts\probe.py <out>.png --thr 170 cols <x1>,<x2>
# 总体量（或 build.ps1 加 -Measure）
python <skill>\scripts\component_geom.py <out>.png --thr 170 --dil 1
# DXF 复查
python <skill>\scripts\dxf_check.py <out>.dxf
```

**网格纸手绘不要跑量测**：格子线占满图，探针/连通域必失真，靠视觉判读。
干净手绘照片反读时阈值放宽 `thr=190~210` + `--dil 2`；贴边黑边会被自动清掉。

## 怎么读探针输出

以中心线附近一行为例（容器样例 `cy=620,D=400`）：

```
行 y=600: (356,358),(399,401),(419,421),(480,483),(580,582),(1003,1005),(1011,1013),(1380,1382),(1479,1482),...
```

- `(580,582)(1380,1382)`：筒体-封头交界竖线 → 直段 800，中心 981。
- `(480,483)(1479,1482)`：封头弧尖端窄段 → 尖点 ≈481/1481。
- `(356,358)(399,401)`：人孔法兰两侧边（厚≈22）。
- **判定**：法兰 x 356–401 < 弧 x 480 → 在尖点**外侧** ✓。若法兰 x 落在弧 x 与交界 x 之间 → 接管画进内侧 = **方向反了**。
- `(1003,1005)(1011,1013)`：隔板双竖线。

## 自动量测的已知失真

1. `component_geom.py` 的"直段长"偏长（弧与母线相切处仍在容差内，每侧约 +80px）。真值取交界竖线列位置。
2. "封头尖点/外伸量"会把连通的法兰/点划线算进包围盒。真值用行探针。
3. `measure_lineart.py` 行覆盖率阈值对照片常不触发，优先 `component_geom.py`。

结论：自动量测兜底趋势，定值用交界线/行探针；三者不一致以探针为准。

## 清理确认（只留 png+dxf）

最终构建用 `build.ps1 ... -Clean`，它会在成功后删除 SVG、`*_preview.png`、`scripts\__pycache__`。交付前确认输出目录**只剩 `.png` 与 `.dxf`**：

```powershell
Get-ChildItem <out目录> -File | Select-Object Name
```

若还有 `.svg`/`_preview.png`/其它过程文件，删掉再交付。`sample_out/` 同样只保留 png+dxf。
